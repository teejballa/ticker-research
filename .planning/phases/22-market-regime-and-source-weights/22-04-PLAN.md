1. **Hierarchical BY-FDR (D-15)** — per-regime BY families + meta-BH across regimes, per Benjamini-Bogomolov 2014 multi-tissue eQTL precedent. import type { RegimeLabel } from '@/lib/regime/types';

```typescript
export interface HierarchicalBYResult {
  per_regime: Record<RegimeLabel, BYResult>;
  meta_bh_decisions: Record<RegimeLabel, 'REJECT' | 'ACCEPT'>;
  effective_q: Record<RegimeLabel, number>;
}

/**
 * Hierarchical BY-FDR per Benjamini & Bogomolov 2014
 * (Selective inference on multiple families of hypotheses, JRSS B 76(1):297-318).
 *
 * Two-stage:
 *   Stage 1 (inner): BY within each regime family.
 *   Stage 2 (outer): BH across regime families using min(per-family adjusted q)
 *                    as the family-summary statistic. Regimes failing meta-BH
 *                    have ALL inner rejections demoted to ACCEPT.
 *
 * Why this preserves power: naive BY across all 4 regimes' cells inflates
 * c(m) from ln(157)≈5.6 to ln(628)≈7.0 (25% denominator inflation). Hierarchical
 * keeps per-regime c(m_r) at the original level, paid for by a small outer BH
 * correction over the 4 family-summary statistics.
 */
export function hierarchicalBYBH(
  perRegimePValues: Record<RegimeLabel, number[]>,
  q_inner: number,
  q_outer: number,
): HierarchicalBYResult;
```
