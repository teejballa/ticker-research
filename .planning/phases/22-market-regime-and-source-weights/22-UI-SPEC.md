# Phase 22 — UI Design Contract

> Visual and interaction contract for the **single additive UI surface** Phase 22 ships: a new "Source mix" row inside the existing `EngineCalibrationPanel` (`src/components/EngineCalibrationPanel.tsx`). The row shows the active 4-bucket regime label, the top-3 sources by learned `(source × regime)` weight, and a click-to-expand panel revealing the full 8-source ranking with a 30-day weight-drift sparkline per source. Generated by gsd-ui-researcher 2026-06-08 (autonomous, `/gsd-plan-phase 22 --chain --auto`). No new page, no new navigation, no new design system. This is an in-place visual extension that must match existing panel density and idiom.

### Expand panel (client island)

**Trigger:** Click the right-side button OR press Space/Enter when it is focused. Toggles `expanded` state. No URL change; no router push; no modal.

**Animation:** `max-height` ease-out 200ms from `0` to `max-content`, plus `opacity` 0→1 with a 60ms delay. NEVER taller than 320px before scrolling — if 8 sources × `~36px` row height exceeds this, the inner list scrolls (`overflow-y-auto`). Drift sparklines do not animate in (avoid Robinhood-style "data appears slowly" anti-pattern).

**Structure (when expanded):**

A `<div data-testid="source-mix-expanded">` directly below the always-visible row, sharing the same `bg-surface-container-high` rounded shell so it reads as one continuous surface (no double-border). Spacer: `mt-2` only.

Inside the expanded shell, a single semantic table:

| col 1 | col 2 | col 3 | col 4 | col 5 |
|-------|-------|-------|-------|-------|
| Rank (★ on row 1, integer 2..8 otherwise) | Source label (uppercase mono) | Weight % (right-aligned, `tabular-nums`) | 30d drift sparkline (60×16px SVG) | 30d delta (`+2.3pp` / `−1.4pp` / `flat`, with directional glyph) |

Header row uses `text-[10px] tracking-widest uppercase text-on-surface-variant` — identical to the existing HorizonTable header (`EngineCalibrationPanel.tsx:412`). One `border-b border-outline-variant` under the header; per-row dividers are `border-b border-outline-variant/40` (lighter).

**Sparkline shape:** Reuses the existing `Sparkline` SVG-only pattern at `EngineCalibrationPanel.tsx:233-250`. Inputs:
- `W = 60` (px)
- `H = 16` (px)
- `data = number[]` (30 trading-day series, length 30; weights as fractions in `[0, 1]`)
- Stroke color picked by 30d slope sign (see Color §Drift sparkline colors).
- One dashed horizontal at the `(source, 'ALL')` unconditional reference weight.

Every sparkline includes a `<title>` element child for accessibility — the title body is the 30d delta number plus the unconditional reference value (e.g. `"+2.3pp vs ALL=0.31 over 30d"`).

**Cold-start row inside the expanded panel:** When a `(source, regime)` cell falls back to the `(source, 'ALL')` row per D-09, that source's row in the table renders:
- Weight `%` as normal (the `'ALL'` weight).
- Sparkline = flat horizontal at `'ALL'` weight, stroke `text-outline-variant` (visually neutral — no drift signal because there is no regime conditioning yet).
- 30d delta column: text `regime-unconditional` in `text-[10px] text-on-surface-variant italic tracking-wide` instead of a delta number.
- Tooltip on the row: `"Falling back to (source, 'ALL') — this (source × {regime}) cell has not yet accumulated enough IC observations to support regime-conditional weights (D-09 cold-start)."`

## Data Contract — what `engine-context.ts` must surface

Per RESEARCH §J line 404, `engine-context.ts` is the authoritative numerics boundary. The UI must consume *only* the shape defined here; it must never compute a weight or a regime label itself.

```ts
// Surfaced on the EngineCalibration block (additive; nullable for back-compat).
interface SourceMix {
  /** Regime label at the report's PIT (matches snapshot.regime per D-08). */
  regime: 'bull-low-vol' | 'bull-high-vol' | 'bear-low-vol' | 'bear-high-vol' | 'ALL';

  /** Up to 8 entries. Sorted DESCENDING by `weight`. Length ≥ 0; may be 0 for sparse cells. */
  top_sources: Array<{
    /** Stable source id; UI maps to SOURCE_LABEL via the Copywriting Contract table above. */
    source_id: 'stocktwits' | 'options_term_structure' | 'finsentllm_ensemble' | 'reddit'
             | 'hackernews' | 'news_analyst' | 'quiver_insider' | 'quiver_congressional';

    /** Regime-conditional weight (post EB-shrink, post softmax-clamp). Fraction in [0, 1]. */
    weight: number;

    /** `(source, 'ALL')` unconditional reference weight. Fraction in [0, 1]. Used as the
        dashed-baseline in the sparkline + the `weight_all_pct` in the title. */
    weight_unconditional: number;

    /**
     * 30-trading-day weight history for this source under the active regime.
     * Length = 30. Each entry is a fraction in [0, 1].
     * Last element corresponds to the report's PIT.
     */
    weight_drift_30d: number[];

    /** Pre-computed slope sign so the UI doesn't compute it.
     *  'rising' if net 30d delta > +1pp; 'falling' if < -1pp; 'flat' otherwise. */
    drift_direction: 'rising' | 'falling' | 'flat';

    /** Net 30d delta in percentage points (signed). UI displays as `+2.3pp`, `−1.4pp`, etc. */
    delta_pp_30d: number;

    /** True iff this row fell back to `(source, 'ALL')` per D-09 cold-start chain. */
    is_cold_start_fallback: boolean;
  }>;
}

// Additive field on the existing EngineCalibration type.
interface EngineCalibrationExtension {
  source_mix?: SourceMix; // undefined for old persisted reports — UI renders nothing.
}
```

The UI assumes the array is already sorted DESC by `weight` and TRUSTS the `drift_direction` field. No re-sorting or re-computation in the component.

## Render Boundaries (RSC vs client island)

Per RESEARCH §Q4, the row splits cleanly:

| Element | Rendering | Why |
|---------|-----------|-----|
| Always-visible row (`SourceMixRow`) | React Server Component (no `'use client'`) | Pure projection from `calibration.source_mix`. Zero interactivity in the visible state until the disclosure button is clicked. Matches `ConformalCIRow` precedent (server-rendered). |
| Expand panel (`SourceMixExpanded`) | Client island — a separate file `src/components/SourceMixExpanded.tsx` with `'use client'` at the top | The disclosure state (`expanded` boolean), the `aria-expanded` toggle, and the sparkline hover-title interactions all require client state. Matches `WatchBadge.tsx:22` precedent for in-panel client islands. |

The always-visible row imports and renders `<SourceMixExpanded sources={source_mix.top_sources} regime={source_mix.regime} />`. The client island handles its own collapsed/expanded state internally — there is no prop drilling for `expanded` from the parent.

## Anti-pattern checklist (what this row must NOT do)

- Must NOT introduce a chart library (recharts, victory, etc.). The sparkline is hand-rolled SVG identical to the existing `Sparkline` primitive at `EngineCalibrationPanel.tsx:233-250`.
- Must NOT introduce a modal, drawer, dialog, or popover library. The "expand" is in-place disclosure.
- Must NOT push to the router or change the URL on expand/collapse.
- Must NOT use any new color outside the Material-3 token set already in `globals.css`.
- Must NOT render at the top of the panel (above the QuadClassPanel). It sits **below** Concept Drift and **above** AlignmentDisagreementBlocks — the panel's hierarchy is: header → calibration grid → horizon table → concept drift → **SOURCE MIX (new)** → alignment/disagreement prose → contradiction warnings → footer. Inserting elsewhere violates the panel's existing visual reading order.
- Must NOT increase the panel's total scroll height by more than ~80px in collapsed state (the row should feel like a peer of Concept Drift, not a new section header).
- Must NOT block the report PDF from printing (see Print behavior — expanded always-visible during print).
- Must NOT compute regime labels, weights, or drift values in the component. All numerics come from `engine-context.ts` per CONTEXT `<code_context>` rule.
- Must NOT introduce per-source brand colors. Source pills are all neutral `text-on-surface` except the #1 leading pill which gets the indigo primary treatment.
