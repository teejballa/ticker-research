/* Composite done-gate for Phase 21.1 — Capacity to Detect Edge.

import { execSync } from 'node:child_process';
import { readFileSync, existsSync } from 'node:fs';

type GateResult = { name: string; passed: boolean; detail: string };

async function gates(): Promise<GateResult[]> {
  const results: GateResult[] = [];

  // Gate 1 — Schema columns present
  try {
    const schema = readFileSync('prisma/schema.prisma', 'utf8');
    const needed = ['is_sigma_hit_k1', 'is_directional_hit', 'is_hit_flat1', 'sector_sigma_60d'];
    const missing = needed.filter(c => !schema.includes(c));
    results.push({
      name: '1. Prisma schema columns',
      passed: missing.length === 0,
      detail: missing.length ? `missing: ${missing.join(', ')}` : 'all 4 PriceOutcome columns present',
    });
  } catch (e) {
    results.push({ name: '1. Prisma schema columns', passed: false, detail: String(e) });
  }

  // Gate 2 — Evaluation primitives + tests
  const primitives = ['bootstrap', 'fdr', 'ic', 'dsr', 'log-loss'];
  const missingMods = primitives.filter(p => !existsSync(`src/lib/evaluation/${p}.ts`));
  let testsPass = false;
  try {
    execSync('npx vitest run src/lib/evaluation/__tests__/ --reporter=dot', { stdio: 'pipe' });
    testsPass = true;
  } catch { /* testsPass remains false */ }
  results.push({
    name: '2. Evaluation primitives + tests',
    passed: missingMods.length === 0 && testsPass,
    detail: missingMods.length ? `missing modules: ${missingMods.join(', ')}` : testsPass ? 'all 5 modules + tests green' : 'modules exist but tests failing',

## Phase 21.1 — Capacity to Detect Edge

Phase 21.1 equips Cipher with five measurement primitives that together let us
answer the IS paper's central question — *does the Gemini-based research engine
produce edge above a non-LLM baseline trained on the same features?* — with
publication-grade rigor.

### Primitives

1. **BCa bootstrap** (Efron 1987, JASA 82(397)). Bias-corrected, accelerated
   non-parametric confidence intervals. 10,000 resamples by default. Used on
   every reported number (CLAUDE.md rule #3): hit rates, Brier lift, IC,
   per-cell posterior, three-way model comparisons.

2. **Benjamini-Yekutieli FDR** (Benjamini & Yekutieli 2001, Annals of Statistics
   29(4)). Multiple-testing correction under arbitrary dependence — appropriate
   because the 156 cells share market regime. Applied across `n_trials_attempted`
   in each `learn` cron run before any cell can graduate to ACTIVE. q ≤ 0.10
   default; documented in HYPERPARAMETERS.md.

3. **Deflated Sharpe Ratio** (Bailey & López de Prado 2014, J. Portfolio
   Management 40(5)). Adjusts in-sample Sharpe for selection bias from cell-space
   exploration. A cell may pass the FDR gate by chance; DSR > 0 is the second
   filter required for ACTIVE status. Inputs: in-sample Sharpe, n_trials, skew,
   kurtosis of the cell's prediction-return series.

4. **Spearman rank IC** (Spearman 1904). Rank correlation between
   confidence-weighted Buy/Hold/Sell directional score and forward
   sector-relative return. The standard quant metric. Rolling 30-day window with
   BCa CI is Cipher's headline IS-paper figure.

5. **Categorical log loss** (CS229 § Information Theory). Proper scoring rule
   alongside Brier (CLAUDE.md rule #7). Punishes overconfident wrong calls.

### Head-to-head baseline

Per CLAUDE.md rule #8, the LLM is benchmarked against two logistic regression
baselines trained on the same Purged K-Fold + Embargo (López de Prado 2018):
- **24-feature** — engine's full z-score-expanded numeric feature space
- **Canonical small set** — 5–7 lit-cited features (RSI, MACD, sentiment%,
  insider net flow, institutional net flow, put/call, sector return)

Both baselines use the Bayesian-Laplace logistic primitive (`predictLogistic` in
`src/lib/learning.ts`) with `PRIOR_PRECISION` chosen via ridge sweep
{1, 2, 4, 8, 16} on OOS Brier.

### Honest outcomes

Per the IS paper's commitment to calibrated null results, three outcomes are all
publishable:
- **A.** LLM beats logistic with BCa CI excluding zero — defensible LLM edge claim
- **B.** Logistic ≈ LLM, both > null — features carry signal, LLM adds nothing
- **C.** Nothing beats null — publicly-available signal set lacks daily-frequency alpha

Phase 21.1 is the *capacity* to distinguish these. The 6-month live soak after
21.1 ships is the *measurement window* that produces the answer.
