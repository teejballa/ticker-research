Create `src/lib/evaluation/fdr.ts`. Implement BY per Benjamini & Yekutieli 2001:

1. Compute `c(m) = Σᵢ₌₁^m 1/i` (harmonic number).
2. Sort p-values ascending; remember original indices.
3. For each sorted rank `i` (1-indexed): threshold = `(i * q) / (m * c(m))`. REJECT if `p_sorted[i-1] ≤ threshold`. Per the BY procedure, find the LARGEST `i` satisfying this and reject all ranks `≤ i`.
4. Adjusted p-value (sorted order): `p_adj[i-1] = min(1, p_sorted[i-1] * m * c(m) / i)`.
5. Monotone enforcement from largest rank down: walk i = m..1, set `p_adj[i-1] = min(p_adj[i-1], p_adj[i])` so the adjusted p-values are non-decreasing in sorted order.
6. Un-sort back to original input order before returning.

Create `src/lib/evaluation/dsr.ts`. Implement DSR per Bailey & López de Prado 2014:

Formula (verbatim from RESEARCH §2.3):
```
σ_SR̂ = √((1 - γ₃·SR̂ + (γ₄-1)/4·SR̂²) / (T-1))
E[max SR₀ across N trials] ≈ √(2·ln(N)) - 0.5772/√(2·ln(N))   (Gumbel max approximation; E-M constant)
SR₀ = σ_SR̂ · E[max SR₀]
DSR = Φ((SR̂ - SR₀) / σ_SR̂)
```

Implementation steps:
1. Guard `T < 30` → return null + warn.
2. Compute `σ_SR̂` from skewness γ₃ and excess kurtosis (kurtosis - 3) γ₄.
3. For `N = 1`, set `SR₀ = 0` (no multiple-testing penalty); DSR collapses to `Φ(SR̂ / σ_SR̂)` (standard Sharpe significance).
4. For `N > 1`, compute `E[max]` via Gumbel approx; multiply by `σ_SR̂` to get SR₀.
5. Return `Φ((SR̂ - SR₀) / σ_SR̂)`.
